## 3. 振り分け不能・不明な場合

次に該当したら**勝手に推測せず、ユーザーに確認**（`AskUserQuestion` 推奨）:
- キーワードが複数領域にまたがり優先順位が判断できない
- 既存の領域にも担当にも当てはまらない
- 機微情報（{{例}}）の取り扱いを伴う

## 4. 連携パターン

- **A 並列**（独立業務）：複数ペルソナを同時 `Task` 起動
- **B 直列**（前→後工程）：{{persona-x}} → {{persona-y}} の順
- **C 主担当＋レビュアー**：オーケストレーターが producer 実行 → 戻り値を受けてレビュアー agent 起動
- **D 統合**：オーケストレーターが複数担当の情報を集約して意思決定ドラフト
