# 日本語ライティング検品

読者に出す日本語を書いたら、出す前にここを通す。
教材記事・LP への実際の赤入れから抽象化したもので、媒体を問わず使う。

## 英語臭を消す（5点）

英語資料を参照しながら書くと構文ごと引きずられる。参照した直後がいちばん危ない。

1. **無生物を主語にして他動詞を続けない。** 英語の直訳になる最大の原因。
   人を主語にするか、主語を省くか、自動詞に変える。
   - ✗ 推測させないことが、そのまま速さになります → ✓ 推測せずに済むぶん、速くなります
   - ✗ 探す手間が、そのまま待ち時間になります → ✓ 探す手間が増えるほど、待たされます
   - ✗ この記事が VS Code を使う理由 → ✓ VS Code を使う理由
2. **主語をいちいち立て直さない。** 英語は毎文に主語を置くが、日本語は前の文から引き継ぐ。
   「ここが」「これが」「それが」で文を起こす癖が出たら、たいていこれ。消しても通じる。
   - ✗ ここが大事なところです。この4つは、業務が変わっても同じです
   - ✓ 4つとも、業務が変わっても同じです
3. **英語の型をそのまま訳さない。** よく出るもの。
   - ✗ この記事を読み終えると、〜できるようになります（By the end of this article…）
   - ✗ 共通しているのは、〜という形です（What these have in common is…）
   - ✗ 〜が要点です／〜が肝です（The key is…）
   到達目標は書いてよい。ただし毎回違う言い方で、地の文として書く。
4. **指示語を多用しない。** これ・それ・あれ・こちら・あちら・ここ・そこ。
   this / that / it を1対1で訳すと増える。名詞に戻すか、消す。
   - ✗ これは能力の問題ではありません → ✓ 能力の問題ではありません（消しても通じる）
   - ✗ ここが「毎月回る」かどうかの分かれ目です → ✓ 書き留めないと、来月また同じところで止まります
   「ここまでで」「そこで直せば」「これだけです」のような慣用は自然なので残す。目安は1本3個以内。
5. **同じ書き出しをくり返さない。** 複数本まとめて書くと同じ型で始めがち。
   30本が同じ書き出しなら、それだけで機械が書いたものに見える。

## 一文検品（3点）

文法は正しいのに、一文だけ取り出すと成立しない型。音読して、聞き返して確かめる。

1. **述語に「誰が？」と聞く** — 文頭で立てた主語と述語をねじらせない。
   - ✗ この教材は…任せられるところまで、順番に進みます（進むのは読者で、主語は教材）
   - ✓ この教材は…任せられるところまで、順番に案内します
2. **動詞に「何を？」と聞く** — 目的語を省かない。書き手には自明でも、初見の読者は補えない。
   - ✗ 入れるところから始めて → ✓ Claude Code を入れるところから
   とくに LP と文章の冒頭。読者はまだ文脈を持っていない。
3. **到達点に「読者は今日、それができないか？」と聞く** — 約束は現在地との差分で書く。
   - ✗ 毎月くり返している仕事が、自分の手で回るところまで（読者はいまも手で回している）
   - ✓ 毎月くり返している仕事を、任せられるところまで

## タイトル・見出しの約束

- **本文に書いていない数字や程度を約束しない。** 「ここまで減る」「失敗しなくなる」は、
  読み終えても答えが無い。数字を出すなら本文に根拠を書く。
  タイトルの数を変えたら、本文の項目数と合っているか毎回数える。
  - ✗ 毎月の作業はここまで減る（どこまで減るのか本文に無い）
  - ✓ 15分で、使える状態になる（本文に「15分くらいです」がある）
- **比べるときは、何と何かを書く。** 読者は1本目から読むとは限らない。
  - ✗ 何が違う道具なのかを知る → ✓ いつものチャット AI と、どこが違うのか
- **教材・LP のタイトルはメリットを言う。** 問題提起や疑問形ではなく、読むと何ができるようになるかを書く。
  - ✗ 同じ頼み方なのに差がつくのは、フォルダのせい
  - ✓ フォルダを整えるだけで、指示が一度で通るようになる

## 体裁

- **名詞で止めない。モノを主語にしない。** UI 文言でとくに。
  - ✗ メールアドレスの確認が済んでいません → ✓ メールの確認がまだです
  - ✗ この記事は会員限定です → ✓ 続きは登録すると読めます
- **太字は1本に5個まで。** 読み飛ばされると詰まる箇所だけ。多いと AI が書いた文章に見える。
- **疑似見出しに太字を使わない。** 段落の頭に太字で小見出しを置くのは英語ブログの型。
  見出しなら `###` にする。表のセルの中でも使わない。

## 適用のしかた

- 書き終えたら、英語臭5点 → 一文検品3点 → タイトルの約束の順に自分の文を通す
- 複数本まとめて書いたときは、書き出しが揃っていないかを必ず見る
- プロジェクト固有の決まり（コードブロックの種別など）は各リポジトリの CLAUDE.md が持つ。
  このスキルと重複させない
