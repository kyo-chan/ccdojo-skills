# Team Builder — 役割を選んで、同時に見てもらう

1つの資料を、校閲・初見の読み手・慎重役・決裁者のような複数の役割に**同時に**読ませ、
結果を1つにまとめて返す。役割は読むだけで、資料は書き換えない。

## 手順

### 1. 使える役割を集める

役割の一覧は毎回その場で集める。固定の一覧をここに書かない。

- Agent ツールで使えるエージェントのうち、`ccdojo:` で始まるもの（このプラグインに同梱）
- あれば `~/.claude/agents/*.md` と `./.claude/agents/*.md`（frontmatter の `name` と `description` を使う）
- 組み込みのエージェント（Explore・Plan・general-purpose など）は、頼まれない限り出さない

表示名は、`description` の先頭にある「〜役」の部分（例: 校閲役）。無ければ識別子をそのまま出す。
1つも見つからなければ「役割が見つかりません。`/plugin` の Installed で ccdojo が有効か確認してください」と伝えて止まる。

### 2. 一覧を見せて、選んでもらう

次の形で出す。説明は1行に収める。

```
使える役割:
1. 校閲役 — 誤字脱字・表記ゆれ・数字の食い違い
2. 初見の読み手役 — 前提なしで読んで、分からないところ
3. 慎重役 — 言い切り・約束・個人情報の危うさ
4. 決裁者役 — 判断に要る情報が揃っているか

番号か名前で選んでください（例: 1,2 / 全部）:
```

### 3. 選択を受ける

- 番号（`1,3`）、名前（`校閲 と 慎重`）、`全部` のどれでも受ける。名前はあいまい一致でよい
- 5つまで。超えたら「5つまでです。どれを残しますか」と聞いて絞る
- 選んだ役割を1行で確認し、まだ聞いていなければ「何を見てほしいですか（ファイル名と、見てほしい観点）」と聞く

### 4. 同時に動かす

- 選んだ役割の数だけ Agent ツールを**1つのメッセージで並列に**呼ぶ。順番に呼ばない
- `subagent_type` には役割の識別子をそのまま渡す（例: `ccdojo:proofreader`）
- `prompt` には、見てほしい資料のパス・頼みごと・「ファイルは書き換えない。指摘だけ返す」を入れる
- 1つが失敗（エラー・空の結果）しても止めない。「校閲役: 失敗 — 理由」と1行書いて、残りの結果で進む

### 5. まとめる

役割ごとの結果を見出しで分けて並べたあと、「まとめ」を付ける。

- 一致した点（複数の役割が同じところを指した）
- 食い違った点（ある役割の直し案が、別の役割の指摘とぶつかる）。どちらを取るかの目安も1行
- 次にやること（直す順に3つまで）

役割が1つだけなら、まとめは付けず結果をそのまま返す。

## 決めごと

- 役割は読むだけ。**資料を書き換えない。** 直すかどうかは、人がまとめを読んでから決める
- 5つまで。増やすほど結果が薄くなり、使用量だけ増える
- 並列で動かす。役割どうしが互いの結果に引きずられないようにするため
- 日本語で返す
